¿Qué es?

Juego arcade educativo para aprender a convertir números hexadecimales a binario. Los marcianos caen con su código hexadecimal; el jugador compone los nibbles binarios con las teclas QWER / UIOP y dispara automáticamente cuando la respuesta es correcta.

Incluye modo libre (dificultad progresiva), niveles fijos del 1 al 5 y modo sala multijugador en tiempo real donde varios alumnos compiten simultáneamente con ranking en vivo.

Autor: José Manuel Lizana Jiménez — Departamento de Informática, IES Ciudad Jardín

Despliegue con Docker (recomendado)

Docker ≥ 24 Docker Compose v2 Git 
# 1. Clonar el repositorio
git clone https://github.com/joseliza/hexagame.git
cd hexagame

# 2. Construir la imagen y arrancar el contenedor
docker compose up --build -d

# 3. Abrir el juego en el navegador → http://localhost:5000

Para detener:

docker compose down

Para actualizar tras cambios en el repositorio:

git pull
docker compose down && docker compose up --build -d

Despliegue manual (sin Docker)

Python ≥ 3.10 pip Git 
# 1. Clonar el repositorio
git clone https://github.com/joseliza/hexagame.git
cd hexagame

# 2. Crear entorno virtual e instalar dependencias
python -m venv .venv
source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 3. Arrancar el servidor
python app.py

# Abrir el juego → http://localhost:5000

Para producción con Gunicorn:

gunicorn --worker-class eventlet -w 1 --bind 0.0.0.0:5000 app:app

Modo sala multijugador

1

Un jugador pulsa Sala multijugador, escribe su nick y deja el código vacío → se crea una sala con un código de 4 caracteres.

2

El resto de jugadores introducen el mismo código de 4 caracteres para unirse a la sala.

3

Cada jugador pulsa Jugar de forma independiente. Las puntuaciones se sincronizan en tiempo real en el panel lateral.

4

El creador de la sala puede mostrar el podio final con el botón 🏆 Podio. Esta acción interrumpe la partida de todos los jugadores.

Las salas se almacenan en memoria; al reiniciar el servidor se eliminan automáticamente.
