¿Qué es?

Juego arcade educativo para aprender a convertir números hexadecimales a binario. Los marcianos caen con su código hexadecimal; el jugador compone los nibbles binarios con las teclas QWER/UIOP y dispara cuando los tiene correctos.

Incluye modo libre (dificultad progresiva), niveles fijos y modo sala multijugador en tiempo real donde varios alumnos compiten simultáneamente viendo el ranking en vivo.

Autor: José Manuel Lizana Jiménez — Departamento de Informática, IES Ciudad Jardín

Despliegue con Docker (recomendado)

Requisitos

Docker ≥ 24 Docker Compose v2 Git

Pasos

# 1. Descarga el proyecto desde GitHub
git clone https://github.com/joseliza/hexagame.git
cd hexagame

# 2. Construye la imagen y arranca el contenedor
docker compose up --build -d

# 3. Abre el juego en el navegador
#    http://localhost:5000

Para detenerlo:

docker compose down

Para actualizar cuando haya cambios en el repositorio:

git pull
docker compose down && docker compose up --build -d

Despliegue manual (sin Docker)

Requisitos

Python ≥ 3.10 pip Git

Pasos

# 1. Descarga el proyecto desde GitHub
git clone https://github.com/joseliza/hexagame.git
cd hexagame

# 2. Crea un entorno virtual e instala dependencias
python -m venv .venv
source .venv/bin/activate        # En Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 3. Arranca el servidor
python app.py

# 4. Abre el juego en el navegador
#    http://localhost:5000

Para producción con Gunicorn:

gunicorn --worker-class eventlet -w 1 --bind 0.0.0.0:5000 app:app

Cómo funciona el modo sala

1. Un jugador pulsa Sala multijugador, escribe su nick y deja el código vacío → se crea una sala con un código de 4 caracteres.

2. El resto de jugadores introducen el mismo código para unirse.

3. Cada jugador pulsa Jugar de forma independiente. Las puntuaciones se sincronizan en tiempo real en el panel lateral.

4. El anfitrión (quien creó la sala) puede mostrar el podio final con el botón 🏆 Podio.

Las salas se almacenan en memoria; al reiniciar el servidor se eliminan.
